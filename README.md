# The Crocus Community

Сайт центра английского для подростков в Астане и маркет за крокус-коины.
Статика без зависимостей: открывается на GitHub Pages.

## Структура
```
src/layout.html      общий шаблон: head, шапка, меню, подвал, таббар
src/pages/*.html     содержимое страниц (сверху — блок настроек)
build.py             собирает страницы в корень: python3 build.py
css/app.css          стили (токены → база → блоки → маркет → кабинет → админка)
js/app.js            точка входа, подгружает модуль страницы по data-page
js/store.js          слой данных (localStorage), асинхронный интерфейс под будущий API
js/seed.js           стартовые студенты и каталог
js/ui.js             форматирование, окна-листы, уведомления, шапка
js/market.js         каталог, поиск, сортировка, покупка, цель
js/cabinet.js        кабинет студента
js/admin.js          панель преподавателя
```

## Правки
1. Меняй файлы в `src/` (не готовые `*.html` в корне).
2. Запусти `python3 build.py`.
3. Закоммить и запушь в `main`.

## Демо-доступ
- Студенты: `TCC-1001`, `TCC-1002`, `TCC-1003`.
- Панель преподавателя: `admin.html`. Пароль проверяется по хешу в браузере. Это демо: для настоящей работы проверку и данные нужно перенести на сервер (например, Cloudflare Worker + D1).
